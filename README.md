# ST558_Project2_SM

This app will allow users to perform various types of data analyses on information from online sales from a Superstore in the U.S.

This data includes information about the consumers purchasing the data such as their location within the U.S., what consumer segment they belong to (business vs personal), as well as information about the product they purchase (such as a product's category and sub-category).  The user will also be able to analyze different data about each order such as the rate of discount the consumer received and how much profit the store made from that order.

The user can choose to analyze either categorical or numeric data only or look at the intersection between the two subsets through various widgets within the app.  Numeric or graphical summaries are available for their preferred analysis method for that data and the subset data is able to be downloaded for future use if they desire.
